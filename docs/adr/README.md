# Décisions d'architecture (ADR)

**Rôle de ce dossier.** `docs/designs/architecture-niveau-1.md` fait foi. Une ADR enregistre une décision prise après le 2026-10-31 qui change une interface, un invariant ou un choix décrit dans ce document. Une ADR acceptée modifie, dans la même pull request, la section du niveau 1 qu'elle concerne. L'ADR garde la raison du changement, et le niveau 1 garde la règle. Une ADR enregistre aussi une décision qui revient sur une option écartée par une ADR acceptée, même si elle ne modifie aucune section du niveau 1. Les décisions du 2026-10-31 restent dans le niveau 1, sans ADR.

## Modèle

Fichier `docs/adr/NNNN-titre-court.md` :

- **Numéro :**
- **Titre :**
- **Statut :** proposée | acceptée | remplacée par n° …
- **Date :**
- **Décideur :** le propriétaire
- **Contexte :**
- **Options :**
- **Décision :**
- **Conséquences :**
- **Condition de révision :**
- **Section du niveau 1 modifiée :**
